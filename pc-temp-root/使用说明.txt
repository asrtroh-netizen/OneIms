PC 便携临时 Root（无 Python）
================================

双击「一键临时Root.cmd」即可。
本目录自带 adb 与 preload so，不需要安装 Python / Android SDK / PowerShell 脚本。

前提
----
1. USB 连接 Pixel（或已授权调试的设备）
2. 手机弹出「允许 USB 调试」时点允许
3. 本机只需能运行 Windows CMD（Win10/11）

用法
----
· 一键执行：双击 一键临时Root.cmd
· 只探测不执行：一键临时Root.cmd dry

会做什么
----
1. 用自带 adb 认机
2. 读 ro.product.device + ro.build.id，选 so\preload-<机型>-<build>.so
   找不到则回落 so\preload-comet.so
3. adb push → 清卡住进程 → LD_PRELOAD 多轮 → 验 su

不会做什么
----
· 不依赖仓库里的 Python oneso / Hub GUI
· 不做运营商配置持久化
· 不保证所有机型一点成功（仍取决于 so 与漏洞条件）

目录
----
adb\     自带 platform-tools 精简文件
so\      集成的 preload*.so + catalog.json（对照用）
sh\      设备侧清理脚本
一键临时Root.cmd   入口
