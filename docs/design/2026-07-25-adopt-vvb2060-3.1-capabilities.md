## 2. 平台铁律（两边都绕不过）

当 `isSystemApp` + `isSdkSandboxUidInternal` 都在时，3.1 也会 `canPersistent=false`，只写 temporary。  
**A17 上「南宫支持」≠「重启真持久」。**

## 3. 落地顺序

1. **Phase 1（本轮）**：`KEY_VOIMS_OPT_IN_STATUS=68` 并入能力应用  
2. **Phase 2（下一轮，需单独验收）**：旁路「沙盒持久写」模块  
   - 仅当探测 `LIKELY_ALLOWED` 且未开强制临时  
   - 独立 Instrumentation（勿污染现有 Broker 主路径）  
   - 失败静默回落现有 Writer  
   - 实验开关默认关  
3. **明确不做**：整包抄 UI、改默认免 Root 主路径、声称破解 system 身份
