# FNHOME Upsnap 远程唤醒配置手册

日期：2026-08-03  
面板：`http://192.168.2.2:8090/`（家局域网）  
远程：本机跑 `scripts/fnhome-upsnap-tunnel.ps1` 后打开 `http://127.0.0.1:18090/`

## 0. 先搞清边界

- Upsnap 跑在 **FNHOME（192.168.2.2）**，魔法包只在 **192.168.2.0/24** 二层有效。
- **单位 PC（192.168.1.7）不能被它唤醒**；单位机只负责「打开面板去唤醒家侧电脑」。
- 目标机必须：**有线网卡**（多数无线 WoL 不可靠）、关机后仍供电、主板/系统打开 WoL。

## 1. 打开面板

1. 家在同一 Wi‑Fi/有线：浏览器开 `http://192.168.2.2:8090/`
2. 人不在家：PowerShell 执行仓库脚本  
   `powershell -ExecutionPolicy Bypass -File scripts\fnhome-upsnap-tunnel.ps1`  
   再开 `http://127.0.0.1:18090/`
3. 登录：邮箱 **`mo@itb.one`** + 你当初设的密码（未重置过）

## 2. 在 Upsnap 里加/改设备

1. 登录后点 **Add device / 添加设备**
2. 必填：
   - **Name**：好认的名字（如「书房主机」）
   - **IP**：目标机固定 IP（建议在小米路由里做 DHCP 保留）
   - **MAC**：目标机有线网卡 MAC（`ipconfig /all` 或路由器客户端列表）
   - **Netmask**：一般填 `24`（对应 /24）
3. 保存后列表里应能 ping 出 online/offline（目标开机时 online）
4. 点设备上的 **Wake** 发魔法包

已预置（可改名）：`家侧-2.55`、`家侧-2.66`——若不是你要唤醒的机器，删掉重加。

## 3. 目标 Windows 机要开的开关

1. **BIOS/UEFI**：`Wake on LAN` / `Power on by PCI-E` 一类选项 → Enabled  
2. **设备管理器 → 网卡 → 电源管理**：
   - 允许此设备唤醒计算机
   - 允许幻数据包唤醒（若有）
3. **快速启动**：建议关掉（控制面板 → 电源选项 → 选择电源按钮功能 → 取消「启用快速启动」），否则有的机子休眠态收不到包  
4. 测一次：关机（不是拔电）→ 面板点 Wake → 看是否亮机

## 4. 验收清单

| 步骤 | 期望 |
|---|---|
| 打开 8090 / 隧道 18090 | 出现 Upsnap 登录/仪表盘 |
| 设备 MAC/IP 正确 | 开机时状态 online |
| 关机后点 Wake | 目标机启动（1～2 分钟内） |
| 从单位机隧道操作 | 与家局域网直连效果相同 |

## 5. 常见失败

| 现象 | 排查 |
|---|---|
| 点了没反应 | BIOS/网卡 WoL 未开；或目标在无线 |
| 面板打不开 | Upsnap 容器是否 Up；隧道是否连着 |
| 能 ping 不能醒 | 快速启动/现代待机；换有线口再试 |
| 想醒单位 PC | 做不到（跨网段）；单位机需办公室侧 WoL |
