# 2026-08-08 · TTFN「搜片/看片」站点方案选型

## 背景

媳妇原先使用的「搜电影 → 出各种网盘链接」站点已 404。希望在家侧（优先 **TTFN**）重建**近似体验**。

## 红线（不做什么）

不做「全网聚合未授权影视网盘直链 / 爬虫索引盗版资源」的站点或后端。该类产品涉及未授权传播，本项目明确排除。

## TTFN 现状（2026-08-08 SSH 采证）

| 项 | 值 |
|---|---|
| 主机 | `TTFN` / `aarch64`（RK3568） |
| 内存 | 7.4Gi（available ≈4.8Gi） |
| 存储 | `/vol1` 205G，约 **192G 可用** |
| 已有应用 | `trim.media`、`trim.photos`、`lite.gallery`、`xunlei`、`npc`、`AdGuardHome` 等 |
| Docker | 存在；当前用户无免密 `sudo docker`（部署容器需授权提权或应用中心） |
| 外网入口 | NPS `tfs.itt.fan:4848`（SSH）；Web 可走既有反代/NPS/Tailscale |

## 合法方案对比

### A. 自有片库影音中心（推荐默认）

**形态**：TTFN 部署 **Jellyfin**（或 Emby）+ 约定目录（如 `/vol1/1000/Media/Movies`）。

| 维度 | 说明 |
|---|---|
| 体验 | 搜片名、海报、简介、直接播放；手机/TV 客户端成熟 |
| 与「各种盘」差距 | 不聚合外站网盘；片源=你们自己放进 NAS 的文件 |
| 成本 | 低；aarch64 有现成镜像；转码吃 CPU（可优先直通） |
| 依赖 | Docker 提权或飞牛应用中心；NPS/域名反代可选 |

### B. 导视站 + 想看清单（最接近「搜一搜」）

**形态**：轻量 Web（Next/FastAPI）接 **TMDB**，搜索电影，展示海报/评分/正版平台（Watch Providers）；支持「想看」清单。可选：一键生成下载任务给 **迅雷/手动**（仅限你们确认有权获取的内容）。

| 维度 | 说明 |
|---|---|
| 体验 | 「搜电影」最像旧站；结果导向正版/元数据，不是网盘直链站 |
| 差距 | 默认不给网盘；若接自建下载队列，需人工审核合法性 |
| 成本 | 开发量中；可跑在 TTFN 或办公室机 |

### C. 仅索引 NAS 已有文件的私人检索

**形态**：扫本地视频目录 + TMDB 刮削元数据 + 简单搜索页（或 Jellyfin 自带库）。

| 维度 | 说明 |
|---|---|
| 体验 | 「搜得到家里有什么」 |
| 差距 | 库空则搜空；不解决「外面随便找片」 |
| 成本 | 最低（常被 A 覆盖） |

## 推荐落地顺序

1. **先定片库目录与权限**（谁上传、放哪）。  
2. **上 A（Jellyfin）** 解决「能搜能看」。  
3. 若仍怀念「搜全世界再决定」，再补 **B 导视站** 做发现层，不接盗版网盘源。

## 待你拍板

- 选 A / B / A+B / 其他合法变体  
- 域名与访问范围：仅家庭 LAN / Tailscale / 公网 NPS  
- Docker 提权方式：飞牛 UI 装应用 vs SSH `sudo`（需口令/授权）
