# 2026-07-14 · 修复出门激活无配对码 / 启动核心无感

## 现象
真机开无线调试 + 热点后，不弹六位码输入；点「启动核心」像没反应。

## 根因
1. 需要码时先跳系统设置，App 弹窗被盖住
2. mDNS 未持 MulticastLock，热点下端口发现易失败
3. 文案误导：六位码在系统「使用配对码配对设备」，不是 App 生成
4. 未装核心时只走下载，用户以为按钮坏了

## 修复
- MulticastLock + pair/connect 并行发现
- NeedPairingCode 先弹窗，弹窗内再开系统无线调试
- 配对说明文案；缺核心更明确提示
- 版本 2.0.13
