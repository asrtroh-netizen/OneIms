# 2026-08-03 · 单位 PC 全站访问失败急救

## 现象

单位侧「每一个都访问不了」。

## 根因（本机证据）

| 项 | 值 |
|---|---|
| 本机网卡 | `192.168.1.7`，网关/DNS `192.168.1.1`（正常） |
| 飞牛 `192.168.1.99` | ping 通，`:7890` 开 |
| **WinHTTP 代理（故障点）** | 曾设为 **`192.168.2.2:7890`**（家里飞牛局域网，单位不可达） |
| 系统代理（浏览器） | `127.0.0.1:3067`（Karing），本轮经其访问百度 **200** |
| 对照 | `192.168.2.2:7890` 超时；`192.168.1.99:7890` **200** |

把单位机器的系统级代理指到家里 `192.168.2.2`，所有走 WinHTTP 的流量都会挂。

## 已做

```text
netsh winhttp reset proxy
→ 直接访问(没有代理服务器)
```

复测：`https://www.baidu.com` → **200**；`gstatic generate_204` → **204**。

## 建议

1. 浏览器若仍异常：看 Karing 是否在跑（`127.0.0.1:3067`）；不要填家里 IP。  
2. 若要用飞牛 Mihomo：代理填 **`192.168.1.99:7890`**，绝不是 `192.168.2.2`。  
3. 避免再用 `netsh winhttp set proxy` 指到跨站点局域网地址。

## 续 · 「100.x 都打不开」（同机）

用户澄清：打不开的是 Tailscale `100.x`，不是公网。

| 检查 | 结果 |
|---|---|
| 本机 Tailscale | `100.118.220.54`（`ddpc`）已登录 |
| `100.82.92.117`（`ddos` 办公室飞牛） | ping 通；`curl --noproxy` → **302** |
| 经系统代理 `127.0.0.1:3067`（Karing）访问同地址 | **502** |
| `100.64.118.44:8965`（TTFN Sub-Store） | **200** |

根因：代理绕过列表只有 `192.168.*` 等，**没有 `100.*`**，浏览器把 Tailscale 流量丢进 Karing → 502。

已改 HKCU `ProxyOverride` 追加 `100.*`，并刷新 WinINET。请**重启浏览器**后再开：

- 飞牛 Web：`http://100.82.92.117/`
- Sub-Store：`http://100.64.118.44:8965/`
