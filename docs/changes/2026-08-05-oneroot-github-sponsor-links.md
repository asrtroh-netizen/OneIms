# OneRoot：推荐 OneIMS GitHub + 赞赏页

## 变更
- 主页与页脚增加 **OneIMS GitHub**（`https://github.com/asrtroh-netizen/OneIms`）与 **赞赏** 入口
- 新增本地 `sponsor.html`：展示与 App 同源的微信赞助码（`sponsor_wechat.jpg`）
- `POST /api/open-url`：白名单外链用系统浏览器打开，避免壳内导航跑飞

## 验证
- 打开 OneRoot → 主区/页脚可见两链
- 点「赞赏」→ 本地赞赏页出码；点「返回」回主页
- 点 GitHub → 系统浏览器打开 OneIms 仓库
