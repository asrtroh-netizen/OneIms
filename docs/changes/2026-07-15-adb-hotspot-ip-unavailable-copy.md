# 2026-07-15 · 热点下「IP 不可用」文案澄清（2.0.17）

## 现象
真机（如 X Fold）开无线调试 + 个人热点后，OneIms 已能弹出六位码输入框，但系统「无线调试」页显示「IP 地址和端口：不可用（Wi-Fi 已断开连接）」，用户误以为 ADB/热点链路坏了。

## 根因（产品误解，非协议故障）
- 内嵌 ADB 走本机 `127.0.0.1` + mDNS 发现配对/连接端口，**不依赖**系统页那一行对外展示的 Wi‑Fi 客户端 IP。
- 手机作为个人热点 AP 时通常不是 Wi‑Fi STA，系统页就会写「Wi‑Fi 已断开 / IP 不可用」——多数机型上这是预期文案。
- 真正阻塞点是：未点开「使用配对码配对设备」拿到六位码，或配对页已关掉导致 pair 端口消失。

## 修复
- 中/英：配对弹窗正文、首页出门激活说明，明确「忽略 IP 行 → 必须点配对码 → 配对页保持打开」。
- 版本 `2.0.17` / `versionCode 26`。

## 验证
- 字符串与版本号 diff 人工核对 PASS
- 真机：热点图标亮 → 点「使用配对码配对设备」能出六位码 → 填入弹窗配对（需人工）
