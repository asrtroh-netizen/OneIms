# 变更说明：首页 OneKu 核心服务总控卡

**日期**：2026-07-14  
**范围**：仅首页顶部大状态卡（`StatusHero`）与其接线；不改底部导航、能力/独家/排障/设置/支持作者页。

## 目标

把首页顶部原 Shizuku/授权语义状态卡，改造成 **OneKu 核心服务总控卡**，对用户隐藏底层通道名称与执行细节。

## 行为

| 状态 | 视觉 | 主按钮 | 进度点亮 |
|------|------|--------|----------|
| 未激活 | 红色警告态 | 立即激活 OneKu | 待命 |
| 已激活休眠 | 白色就绪态 | 一键恢复通话 | 待命 + 激活 |
| 执行中 | 就绪态 + 按钮禁用 | 正在恢复… | 待命 + 激活 + 执行 |
| 完成 | 白色就绪态 | 检查 OneKu 状态 | 四阶段全亮 |

进度阶段文案：待命 → 激活 → 执行 → 完成。

## 实现要点

- 复用原 Hero 外壳：位置、`extraLarge` 圆角、红/白语义色、左侧图标；页眉右上 SIM 胶囊不变。
- 卡片内新增：右上状态胶囊、轻量四阶段进度、主按钮与副文案。
- 状态策略：`OneKuCardPolicy`（可单测）；底层仍映射既有特权就绪/重应用，UI 不暴露 Shizuku/终端。
- 首页激活/授权相关 Snackbar 改为 OneKu 文案。
