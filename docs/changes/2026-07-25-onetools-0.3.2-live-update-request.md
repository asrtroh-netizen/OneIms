# OneTools 0.3.2 — Live Update 胶囊申请修复

## 根因

状态栏只显示 ↑↓ 箭头、没有速度胶囊：未正确申请 promoted ongoing。

错误用法：`Notification.Builder.setFlag(FLAG_PROMOTED_ONGOING, true)`（系统提升后的结果标志）。

正确用法（与 Pixel Meter / 官方 Live Update 文档一致）：`setRequestPromotedOngoing(true)` + `setShortCriticalText`，并声明 `POST_PROMOTED_NOTIFICATIONS`。

## 改动

- `SpeedMonitorService`：改用 `setRequestPromotedOngoing`，并写入 `EXTRA_REQUEST_PROMOTED_ONGOING`
- OneMeter：增加「打开系统实时更新权限」入口与提示文案
- 版本：`0.3.2` / versionCode `14`

## 验收

1. 覆盖安装 `OneTools-v0.3.2-latest-debug.apk`
2. 开启监测；OneMeter 勾选「状态栏胶囊」
3. 若仍只有箭头：点「打开系统实时更新权限」允许后看状态栏是否出现 `xxxB/s` 胶囊
