# 2026-07-15 · 启动核心立刻弹六位码 / 禁止失败跳走

## 现象
真机开无线调试 + 热点后点「启动核心」：不弹六位码输入，按钮像没反应（与 2.0.13 修复前体感相同）。

## 根因
1. 六位码弹窗原先等 `activate()` 返回 `NeedPairingCode` 才显示；热点下 mDNS/连接要数秒，用户先感觉「没用」
2. `Failed` 回落调用 `prepare()` 会自动跳系统设置，把尚未出现的输入框盖掉
3. 工作树一度删除 `assets/onekuku-core.apk`，未装核心时无法内置安装，只会下载失败，永远进不了配对流程

## 修复
- 核心已安装时：点「启动核心」**立刻**弹出配对窗，再后台跑内嵌 ADB
- 失败时保留弹窗、只复制指引，不再自动跳设置
- 恢复内置 `onekuku-core.apk`
- 版本 2.0.15 / versionCode 24
