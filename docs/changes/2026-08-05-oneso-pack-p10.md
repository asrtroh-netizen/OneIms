# OneSo：P10 全家桶入库

## 机型

`blazer` / `frankel` / `mustang` / `rango`（Pixel 10 家族）

## 做法

- 新增 `python oneso.py pack-p10`：从 `OneSo-assets/so/<build>/` **原样导入**（不改 label）。
- 默认 build：`CP2A.260605.012`（assets 当前齐套档；**无** P10×`CP2A.260705.006`）。
- 与 P9 的 `pack-0705` 分离：P10 so 体积/标签槽不同，禁止拿 P9 0705 so 交叉改名。

## 验证

`pack-p10` → **ok=4/4**；OneIMS `catalog.json` 已含四机型 @ `CP2A.260605.012`。

## Hub / GUI

- Hub：`生成 P10·0605`
- Tk GUI：`导入 P10 全家桶`
