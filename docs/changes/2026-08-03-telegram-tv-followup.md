# 电报 / TV 跟进（2026-08-03）

## 电报

### 发现
- `📲 电报消息` 原先选中 `☠️自建USHOME`，延迟偏高（~1389ms）。
- 公共 DNS（`223.5.5.5`）对 `api.telegram.org` 返回 `199.96.59.95`（**不在** Telegram 官方网段）→ 污染。
- 飞牛侧规则本身会命中电报域名/CIDR。

### 已做
1. 将 `📲 电报消息` 切换为 `🇺🇲 美国节点Pro`（测速约 908ms，优于自建）。
2. 在 `dns.nameserver-policy` 增加 telegram / t.me / telegra.ph / geosite:telegram → Cloudflare/Google DoH。
3. 重启 Mihomo 后复测：
   - Mihomo DNS：`api.telegram.org → 149.154.166.110`（官方网段）
   - 经 `7890` 访问 `api.telegram.org/bot.../getMe` → **HTTP 401**（假 token 预期；证明 API 可达）

### 客户端注意
- 手机/PC 若网关仍是 `192.168.2.1` 且不走飞牛代理，仍可能吃到污染 DNS。
- 建议：系统代理指 `192.168.2.2:7890`，或网关改为 `192.168.2.2` 吃 TUN。

## TV

### 飞牛侧就绪
- `allow-lan: true`
- `tun.enable: true` + `dns-hijack: any:53`
- 监听 `7890/9090/1053`

### 需要你在电视上做（本轮无法代操作）
1. 电视改为静态 IP（同网段 `192.168.2.0/24`）
2. **网关 = `192.168.2.2`（飞牛）**
3. DNS = `192.168.2.2`（或任意，TUN 会劫持 53）
4. 播 YouTube / Netflix 验收

说明：飞牛主机自己的默认路由可继续 `via 192.168.2.1`；**只有电视/要透明代理的设备**把网关指到 `2.2`。

当前 ARP 未见电视主机，说明电视可能仍指向 `2.1/2.5` 或未上线。
