# 3.2.5：修复 Lite `new_process_unavailable`

## 现象

亮屏手点 Lite 3.2.4 一键临时 Root，立刻 snackbar：

`一键临时 Root 失败：new_process_unavailable`

## 根因

`rikka.shizuku.Shizuku.newProcess(String[], String[], String)` 在 api-13.1.5 中为 **private static**。  
旧代码用 `Shizuku::class.java.methods`（只枚举 public）查找，永远 miss → 返回 null。

## 修复

1. `getDeclaredMethod(...)` + `isAccessible = true` 后 `invoke(null, cmd, null, null)`  
2. 生命周期改走 `alive()` / `waitForTimeout()`——`Process.isAlive()` 会间接触发 `exitValue`，被 Shizuku 包成 `RuntimeException("process hasn't exited")`  
3. 同步修 `onebattery` 同构反射  

版本 **3.2.5 / 86**。
