# 电报 7890 vs 静态网关 / TV 只能网关（2026-08-03）

## 用户现象
- 电报：静态 IP（网关模式）可以；填 `7890` 不行。
- 电视：只能静态 IP，无法填 `7890`。

## 服务端证据
在飞牛本机验证（`allow-lan: true`，`bind-address: '*'`）：

| 探测 | 结果 |
|---|---|
| `http://127.0.0.1:7890` → Telegram API | **401**（假 token，表示代理通） |
| `socks5://127.0.0.1:7890` | **401** |
| `socks5://127.0.0.1:7891` | **401** |
| `http://192.168.2.2:7890`（飞牛自身） | **401** |
| INPUT 防火墙 | policy ACCEPT；并加了 LAN `192.168.2.0/24`→7890/7891/9090 |

结论：**飞牛侧 7890/7891 监听与出站正常**；问题在客户端用法或客户端不在 `192.168.2.0/24`。

## 已加固
- `lan-allowed-ips`：显式放行常见私网
- 新增 `socks-port: 7891`（纯 SOCKS，避免和 HTTP 混用搞错）
- `📲 电报消息` 维持可用美国节点

## 电报怎么设

### 方案 A（你已验证可用，推荐）
- 静态 IP，网关 = `192.168.2.2`
- DNS = `192.168.2.2`
- **不用填 7890**（走 TUN 透明代理）

### 方案 B（一定要填代理时）
Telegram 必须用 **SOCKS5**，不要用 HTTP：
- 服务器：`192.168.2.2`
- 端口：`7890`（mixed）或 `7891`（纯 SOCKS）
- 类型：**SOCKS5**
- 设备需在 `192.168.2.0/24`；网关可仍是 `192.168.2.1`

## 电视怎么设（只能这样）
电视不能填 7890 是正常的，请用网关模式：
1. 静态 IP（`192.168.2.x`）
2. 网关 = `192.168.2.2`
3. DNS = `192.168.2.2`
4. 播 YouTube 验收

飞牛主机自己的默认路由可继续 `via 192.168.2.1`。
