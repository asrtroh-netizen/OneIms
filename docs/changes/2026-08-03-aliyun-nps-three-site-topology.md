## 三地角色（本轮已摸到）

| 地点 | 怎么进 | 主机事实 | 本轮相关能力 |
|---|---|---|---|
| A 办公室飞牛 | `192.168.1.99:22` `admin` | hostname `DDOS` | Mihomo TUN 网关已修好；Ange `:2048` |
| B TTFN | `tfs.itt.fan:4848` `TTFN` | hostname `TTFN`；npc→NPS | TUN/FORWARD/DNS53 已同步；Ange/Sub-Store 等 |
| C FNHOME | `hfs.itt.fan:1818` `Halo` | hostname `HaloXFN` | TUN 网关已开；经 SSH 隧道可进上级小米 BE6500（`192.168.2.1`） |

## 和「小米后台隧道」的关系

办公室电脑不在 C 的局域网里 → 不能直连 `192.168.2.1`。  
路径是：**本机 → NPS 公网端口 1818 → HaloXFN SSH → 同局域网小米路由**（再加 Host 改写避免 502）。
