# OneTools 0.3.3 — 摄像头旁「类灵动岛」悬浮

## 边界

系统 Live Update 胶囊位置由 Pixel SystemUI 决定，第三方 App 无法挪到挖孔旁。

## 方案

悬浮网速按 `DisplayCutout` 最大 bounding rect（摄像头孔）贴到左右空隙，并允许 `LAYOUT_IN_DISPLAY_CUTOUT_MODE_SHORT_EDGES` 画进状态栏带；一键「贴到摄像头旁」同时套用紧凑胶囊样式。

## 验收

1. 授予悬浮窗权限 → OneMeter →「贴到摄像头旁（类灵动岛）」
2. 悬浮岛应出现在摄像头孔旁；可拖微调
3. 系统胶囊位置不变属预期
