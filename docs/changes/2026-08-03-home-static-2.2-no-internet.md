# 2026-08-03 · 家侧静态填 2.2 后全网上不了

## 现象

SSH（经 NPS `hfs.itt.fan:1818`）已通，但家里 PC「静态到 2.2」后浏览器什么网都上不了。

## 根因（本轮 SSH 实采）

| 检查 | 启动 mihomo 前 | 启动后 |
|---|---|---|
| `docker` 容器 `mihomo` | **不存在/未跑** | **Up** |
| `Meta` TUN 网卡 | **无** | **UP** |
| UDP `:53` DNS | **无监听**（仅 avahi `:5355`） | **mihomo 监听 `*:53`** |
| `dig @127.0.0.1 www.baidu.com` | N/A | **NOERROR → 183.2.172.177** |
| Meta API `:9090/version` | 空 | `v1.19.29` |
| npc | 在跑 | 在跑（故 SSH 通） |

飞牛自身出网正常；**缺的是网关能力**（TUN + DNS）。  
设备按旧文档把 **网关/DNS 填 `192.168.2.2`** 时，流量打到飞牛却无人转发/解析 → 全站打不开。SSH 走的是进程连通，不依赖这段网关路径。

另：`192.168.2.2` 是飞牛本机地址。**PC 自己的 IP 绝不能静态成 2.2**（会与飞牛冲突）。

## 已在 FNHOME 执行

```bash
cd /vol1/1000/docker/mihomo && docker compose up -d
/opt/mihomo/scripts/enable-lan-forward.sh
```

## 家里 PC 该怎么填（对照）

### A · 先求稳上网（推荐现在就改）

| 项 | 填什么 |
|---|---|
| IP | DHCP，或静态 `192.168.2.x`（**不要** `.2`） |
| 掩码 | `255.255.255.0` |
| 网关 | **`192.168.2.1`**（小米 BE6500） |
| DNS | **`192.168.2.1`** + `223.5.5.5` |

### B · 想继续走飞牛 TUN 网关（mihomo 已拉起后）

| 项 | 填什么 |
|---|---|
| IP | 同上，**不要** `.2` |
| 网关 | `192.168.2.2` |
| DNS | `192.168.2.2`（可备选 `223.5.5.5`） |
| 代理 | 关系统 HTTP 代理；别再套一层浏览器代理 |

若 B 仍不行 → 立刻退回 A。

## 验证

- PC：`nslookup www.baidu.com` 有 IP，浏览器能开百度  
- 飞牛：`docker ps` 见 `mihomo`；`ss -ulnp | grep :53` 见 mihomo  

## 远程侧说明

Cursor 所在单位 PC（`192.168.1.7`）无法直接改你家网卡；本轮已远程修好飞牛 mihomo。家 PC 静态项仍需你本机确认。
