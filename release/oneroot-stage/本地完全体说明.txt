# OneRoot（本地完全体）

本目录是 **Python 单窗完整版**（oneso hub + 工厂 CLI），仅作者本机自用。
版本：`2026.08.05.1`（含详细诊断日志模块 `diaglog.py`）

## 启动

- 双击 `一键启动.cmd` / `OneRoot.cmd`
- 或：`.\OneRoot.ps1`
- 或：`python oneso.py hub`

仓库根 `OneRoot.bat` 也会转到这里。

公开分发请用 OneSo-assets 的 `OneRoot-Lite.zip` / `OneRoot-UI.zip`（不是本目录）。

## 详细诊断日志（他机排障用）

- 每次启动 Hub 会在 `logs/session-时间戳/` 落盘完整过程（不截断）。
- 窗内点 **「导出诊断日志」** → 生成 `logs/OneRoot-diag-*.zip` 并打开目录。
- 把该 zip 原样发回作者即可（含 `session.log` + 脱敏后的 `meta.json`）。
- 命令行自检：`python diaglog.py smoke`
- API：`GET /api/diag` · `POST /api/diag/export` · `POST /api/diag/open`

## 他机若出现「本地服务未响应 / Failed to fetch」

1. 必须用 `一键启动.cmd` / `OneRoot.ps1` 启动，不要双击 `web\index.html`。
2. 不要关闭启动后的黑窗（关掉 Python 进程 = API 立刻死）。
3. `config.json` 里作者机器的 `oneims_root` / `exploit_root` 在他机可以无效；Hub 状态页不应再因此崩掉（2026-08-05 已修）。
4. 仍失败时：删 `%TEMP%\oneroot-single.lock`，关掉残留 Edge OneRoot 窗，再启动；系统代理请放行 `127.0.0.1`。
5. 把窗内「导出诊断日志」打出来的 zip 发回（比截图完整）。
