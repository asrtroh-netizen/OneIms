OneRoot-UI · UI 版（PowerShell 窗体 · so 仅云端）
======================================

双击后打开进度窗：进度条、设备监测、实时日志、
OneIMS 推荐（GitHub / Releases）、微信赞赏码。
窗口底部有「清理残留」按钮（同 Hub 清理语义）。

so 运行时从 GitHub OneSo-assets 拉取并校验 SHA256；
包内不再附带 preload-*.so，避免本地 hash 漂移。需要联网。

依赖：系统自带 Windows PowerShell（不需要单独装 Python）。
成功后重绑 Shizuku：仅 adb shell（shell uid）；
严禁 su -c libshizuku（会出 root 态 server、App 掉线）。

用法
----
双击：一键临时Root.cmd
仅探测：一键临时Root.cmd dry
清理残留：清理残留.cmd
         或 一键临时Root.cmd cleanup
强力清理：一键临时Root.cmd cleanup-aggressive

赞赏码：窗口右侧 WeChat Sponsor（assets\sponsor_wechat.jpg）
