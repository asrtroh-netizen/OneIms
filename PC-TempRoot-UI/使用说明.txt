PC-TempRoot-UI · 增强版（纯 CMD · 无 PowerShell）
==============================================

全部是 CMD：彩色进度、菜单、OneIMS 推荐、微信赞赏码。
不调用 powershell.exe，不依赖 .ps1。

用法
----
双击：弹出菜单
  1 Start temp root
  2 Dry-run
  3 Open OneIMS GitHub
  4 Open Releases
  5 Show WeChat sponsor QR

命令行：
  一键临时Root.cmd dry nopause
  一键临时Root.cmd run
  一键临时Root.cmd github
  一键临时Root.cmd sponsor

赞赏码文件：assets\sponsor_wechat.jpg（与 App 同源）
